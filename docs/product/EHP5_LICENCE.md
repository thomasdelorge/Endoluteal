# Statut de licence EHP-5

L’EHP-5 (Endometriosis Health Profile) est diffusé par Oxford University Innovation. L’usage, y compris gratuit, peut exiger un accord.

Aucun accord n’a été obtenu. Endoluteal ne reproduit pas le texte ni le barème officiel de l’EHP-5.

Le questionnaire mensuel livré est **inspiré** : formulations originales, score indicatif 0–100 calculé dans l’application, libellé comme tel dans l’interface (`monthly_questionnaire_title`).
